# java-racingcar-precourse

> 본 프로젝트는 우아한테크코스 8기 프리코스 과정의 2차 과제로, 주어진 요구사항에 따라 자동차 경주 게임을 구현하는 것을 목표로 합니다.

## 유의사항

- 실행 환경: JDK 21
- 시작점: `Application.main()` 메소드
- camp.nextstep.edu.nissionutits 에서 제공하는 Randoms 및 Console ApI를 사용하여 구현
- 제공하는 라이브러리 외 외부 라이브러리 사용 금지
- 종료: `System.exit()` 호출 금지
- 코드 스타일: [**우아한테크코스** Java Style Guide](https://github.com/woowacourse/woowacourse-docs/tree/main/styleguide/java) 준수
- 커밋 메시지: [AngularJS Git Commit Message Conventions](https://gist.github.com/stephenparish/9941e89d80e2bc58a153) 준수
- build.gradle 파일 수정 금지
- 제공된 파일, 패키지 이름 수정 및 이동 금지
- indent depth는 2까지 허용
- 3항 연산자 사용 금지

## 요구사항 명세서

### 입출력

- [X] `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`를 출력한 뒤, 사용에게 경주할 자동차들의 이름을 입력받는다.
  - 자동차명은 쉼표를 기준으로 입력받는다.
  - 자동차명은 쉼표와 공백을 포함할 수 없으며, 5글자를 초과할 수 없다.
  - 전체 문자열은 1024자로 제한한다.
- [X] `시도할 횟수는 몇 회인가요?`를 출력한 뒤, 사용자에게 자동차를 몇 번 이동할 것인지 정수(이하 n)를 입력받는다.
  - n은 2147483647 이하의 자연수만 가능하다.
- [X] 매 시도가 끝날 때마다 `{자동차명} : -`의 형태로 모든 자동차의 진행 현황을 출력한다.
  - 첫 자동차 이동 연산 수행 전에 `실행결과`를 출력한다.
- [ ] 모든 이동을 마치면 가장 멀리 전진한 자동차의 이름을 `최종 우승자 : {자동차명}` 형태로 출력한다.
  - 우승자가 여러명일 경우, 각 자동차명을 쉼표로 구분하여 출력한다. 
- [ ] 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고 애플리케이션을 종료한다.

### 자동차 이동 계산

- [X] 자동차는 n번만큼 진행을 시도한다.
  - n은 2147483647 이하의 자연수이다.
- [X] 자동차는 0~9 사이의 무작위 값에 따라 전진하거나 정지한다.
  - 값이 4 이상일 경우에는 자동차가 진행한다.
  - 값이 3 이하일 경우에는 자동차가 정지한다.

### 우승자 판별

- [ ] 가장 멀리 이동한 자동차를 최종 우승자로 선정한다.
  - 만약 가장 멀리 이동한 자동차가 여러대일 경우, 공동 우승자로 선정한다.

## 테스트 사항

### 정상 케이스

- 전진 / 멈춤
  - 무작위 값이 4 이상일 경우 전진한다.
  - 무작위 값이 3 이하일 경우 정지한다.
- 우승자 판별
  - 가장 멀리 이동한 자동차가 한 대일 경우, 해당 자동차가 최종 우승자가 된다.
  - 가장 멀리 이동한 자동차가 여러대일 경우, 최종 우승자는 여러대가 된다.
- 입출력 포맷
    - 가장 멀리 이동한 자동차가 한 대일 경우, 해당 자동차의 이름만 `최종 우승자 : {자동차명}`의 형태로 출력한다.
    - 가장 멀리 이동한 자동차가 여러대일 경우, 해당 자동차들의 이름을 `최종 우승자 : {자동차명1},{자동차명2}...`의 형태로 출력한다.

### 예외 케이스 (IllegalArgumentException 발생)

- 자동차명이 쉼표나 공백을 포함하거나, 5자를 초과하는 경우
- 입력값이 공백이거나 null인 경우
- 쉼표 앞, 사이, 뒤에 이름이 없는 경우
- n이 2147483647 이하의 자연수가 아닌 경우
